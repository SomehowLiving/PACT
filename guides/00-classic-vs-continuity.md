# Classic vs Continuity

> **Update 18 Oct 2026 — decision: Continuity.** The app in `pact/` was written before kickoff, so it competes on the Continuity track. Definitive’s Continuity-only prize (Most Creative, $2,500) and Arc’s Continuity bounty ($3,000) are open to it, and the Definitive Social App prize ($2,500) lists no restriction. The text below is the original Classic analysis, kept for reference. Prize amounts below are stale: the live pages show Definitive = two $2,500 prizes, not $3,500 + $1,500.

**Access:** 2026-10-13. Source: https://ethglobal.com/events/mumbai/info/details

## Decision

**Ship Classic (Start Fresh)** unless you already have an open-source trading product you intend to extend.

Classic is how you stay eligible for partner prizes and Finalists. Prior **project-specific code** disqualifies those.

This repo is research, specs, and integration guides. That is preparation. It is **not** the PACT application.

## What you may do before Thu 5 Nov 2026

- Read Flash / wagmi / viem docs
- Create a Definitive **email** account and a Flash API key
- Fund two tiny Base wallets (ETH for gas + ~25–50 USDC)
- Practice a quote in the Flash docs playground with the public key
- Write design docs (this folder)
- Recheck prize pages

## What you must not commit before kickoff (Classic)

- Next.js / React screens named Leader / Follower / PACT
- A `policyEngine` implementation in a product package
- Flash quote→sign→submit scripts checked into **this** (or any) project repo as the hackathon codebase
- Contracts, ABIs, or a copy-trading protocol

If you write learning scripts on a scratch machine, keep them **out of the GitHub you will submit**.

## Continuity (only if you choose it)

Definitive publishes a **Continuity-only** extra **$1,500**. The **$3,500 social** prize is the primary target; partner eligibility on Continuity “may vary.” 1inch also has a Continuity Aqua extra.

Continuity requires documenting pre-existing work and proving new work happened during the event. Large single commits can still be disqualified.

**Default:** Classic. Create the app repo at hour 0. See [08-hour-zero.md](08-hour-zero.md).
